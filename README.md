# Hospital Management System

## 📌 Project Overview

The Hospital Management System is a Java-based console application developed to manage basic hospital operations using JDBC and MySQL. It connects a Java application to a MySQL database to store and retrieve hospital-related information.

## ✨ Features

- Manage hospital-related records.
- Connect to a MySQL database using JDBC.
- Perform database operations using SQL queries.
- Interact with the application through a menu-driven console interface.

## ⚙️ Prerequisites

Before running the project, install:

- Java Development Kit (JDK)
- MySQL Server
- Eclipse IDE (or another Java IDE)
- MySQL Connector/J

## 🚀 How to Run

1. Clone or download this repository.
2. Open Eclipse and import the project.
3. Create the required hospital database and tables in MySQL.
4. Update the JDBC URL, database username, and password in your local configuration.
5. Add the MySQL Connector/J JAR to the project's Java Build Path.
6. Run `HospitalManagementSystem.java` as a Java Application.

## 🗄️ Database Configuration

The project uses MySQL for data storage and JDBC to communicate with the database.

Example JDBC URL:

```java
jdbc:mysql://localhost:3306/hospital
```

Configure your own MySQL username and password locally. **Do not upload database credentials to GitHub.**
